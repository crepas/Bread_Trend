# 🍞 전국 빵 트렌드 분석 (Bread_Trend)



## 🎯 프로젝트 개요



### 📋 프로젝트명

**전국 빵 트렌드 분석: 소셜미디어 기반 베이커리 트렌드 변화 연구**



---



### 🌟 프로젝트 배경 및 목적



현대 소비자들의 라이프스타일 변화와 SNS 문화의 확산으로 베이커리 시장에서도 빠른 트렌드 변화가 일어나고 있습니다. 



**주요 트렌드 변천:**

- **2020-2021**: 코로나19로 인한 홈베이킹 붐 (크로플, 맘모스빵)

- **2022-2023**: 소금빵 열풍 ('본질' 중시 트렌드)

- **2024-2025**: 흑백요리사 영향, 프리미엄 베이커리 트렌드 (밤티라미수, 크루키 등)



이처럼 빠르게 변화하는 베이커리 트렌드를 데이터 기반으로 분석하여 소비자 선호도의 변화 패턴을 파악하고, 향후 트렌드를 예측할 수 있는 인사이트를 도출하고자 합니다.



---



### 🎯 연구 목표



**주요 목표:**

- 소셜미디어(네이버 블로그) 데이터를 활용하여 빵 트렌드의 시계열 변화 패턴 분석



**세부 목표:**

1. 2022-2025년 인기 빵 종류의 시계열 변화 추이 분석

2. 연도별 급등 빵 트렌드 식별 및 원인 분석

3. 향후 6개월 내 주목받을 빵 트렌드 예측

4. 데이터 기반 베이커리 트렌드 변천사 정리



---



### 📈 기대 효과



**학술적 가치:**

- 소셜미디어 기반 소비자 트렌드 분석 방법론 개발

- 웹 크롤링 및 형태소 분석 기술 활용 사례 연구



**산업적 활용:**

- 베이커리 업계의 신제품 개발 전략 수립

- 소상공인 창업자의 메뉴 구성 의사결정 지원



**사회적 의의:**

- 소비자 문화 변화 패턴에 대한 데이터 기반 이해 제공

- SNS가 식품 트렌드에 미치는 영향 분석

## 📊 사용 데이터



### 📝 네이버 블로그 포스팅 데이터



**수집 대상:**

- "빵지순례" 키워드 검색 결과

- 전국 빵집 방문 후기 및 베이커리 리뷰 블로그 글



**수집 방법:**

- 도구: Python + Selenium

- 기간: 2022년 1월 ~ 2025년 11월 (47개월)

- 수집 방식: 월별 균등 수집 (각 달 5페이지)



**수집 내용:**

- 포스팅 제목 및 본문 텍스트

- 작성 연도/월 (year, month)

- 게시 날짜 (date)

- 링크 (link)

- 추출 키워드 (bread_keywords)



**예상 규모:**

- 약 1,600~2,000개의 블로그 글

- 월평균 35개 × 47개월



---



### 🔍 키워드 추출 방법



**1단계: 트렌드 사전 매칭**

```

최신 유행어 우선 매칭:

- 밤티라미수, 크루키, 두바이초콜릿

- 수건케이크, 티슈식빵, 피스타치오

- 프레첼, 퀸아망, 개성주악 등

```



**2단계: 형태소 분석**

```

도구: KoNLPy (Okt)

방법: 명사 추출 + "빵" 포함 단어 필터링

정규화: 크로와상 → 크루아상, 도너츠 → 도넛

```



**3단계: 노이즈 제거**

```

제외 키워드:

- 행위: 베이킹, 홈베이킹

- 장소: 빵집, 제과점

- 일반명사: 식빵, 케이크, 쿠키

```
